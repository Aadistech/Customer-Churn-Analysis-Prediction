Developer REST API Reference

Integrate customer churn predictions directly into CRM software or third-party web apps using our JSON API.

POST /api/predict

Submits single customer telemetry parameters and returns JSON risk scores, drivers, and recommendations.

  "success": true,
  "prediction": "CUSTOMER WILL CHURN",
  "is_churn": true,
  "churn_probability": 78.5,

  "risk_level": "HIGH",

    "🚨 Frequent customer service calls (≥4 calls)",

  ],
