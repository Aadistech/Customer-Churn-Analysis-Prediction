💡 System Mission & Tech Stack Architecture

AadiBI Customer Churn Intelligence System empowers telecom operators, product managers, and enterprise executive leaders to proactively identify subscribers at high risk of cancellation before churn occurs. Built using regularized Random Forest machine learning models and real-time cloud data pipelines, the system transforms raw customer usage telemetry into actionable retention strategies.

🤖 Machine Learning
Scikit-Learn Random Forest

Hyperparameter regularized (92.5% test accuracy, 0.933 ROC-AUC).

Developer REST API Reference

Integrate customer churn predictions directly into CRM software or third-party web apps using our JSON API.

POST /api/predict

Submits single customer telemetry parameters and returns JSON risk scores, drivers, and recommendations. 

{
  "success": true,
  "prediction": "CUSTOMER WILL CHURN",
  "is_churn": true,
  "churn_probability": 78.5,
  "stay_probability": 21.5,
  "risk_level": "HIGH",
  "drivers": [
    "🚨 Frequent customer service calls (≥4 calls)",
    "🔥 High daytime usage (≥250 mins)"
  ],
  "recommendation": "🔥 URGENT: Deploy proactive retention team within 24h."
}
