About This Project

The Customer Churn Analysis & Prediction System (AadiBI) is an enterprise-grade Machine Learning web application engineered to analyze customer behavioral trends, detect accounts with elevated churn probability, and provide transparent risk factors to drive proactive customer retention.

Core Capabilities & System Modules

🎯 Machine Learning Engine

Powered by a trained Random Forest Classifier mapping 69 behavioral feature inputs (account duration, international plans, day/evening/night usage, support call counts) to calibrated churn probabilities.

📊 Visual BI Analytics Dashboard

Renders real-time executive KPI metrics, interactive Chart.js doughnut & bar charts, churn distribution breakdown, and automated risk level classification (`HIGH`, `MEDIUM`, `LOW`).

⚡ Batch Data Ingestion (CSV / XLSX)

Supports batch CSV and Excel dataset uploads to score hundreds of customer accounts simultaneously, automatically clean categorical states, and output downloadable prediction reports.

🛡️ Rule-Based Retention Guidance

Generates transparent risk signals (e.g. frequent support calls, excessive daytime usage) and actionable, time-sensitive retention recommendations for high-risk accounts.

System Execution Pipeline

1

Data Ingestion & Preprocessing

Raw customer datasets are loaded, missing values imputed, categorical variables mapped (`Yes`/`No` -> `1`/`0`), and state codes one-hot encoded into 69 feature vectors.

2

Feature Scaling & Alignment

Feature inputs are scaled via StandardScaler and aligned against exact training column indexes.

3

Model Inference (Random Forest)

The trained Random Forest model predicts binary churn labels (`0` = Stay, `1` = Churn) and calculates exact probability confidence scores.

4

Dashboard Rendering & Export

Results are compiled into real-time KPI metrics, dynamic Chart.js visualizations, risk signals, and exported as a CSV report.
